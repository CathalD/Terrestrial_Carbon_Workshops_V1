## The calculator, in one paragraph

Planning starts from the normal multiplier *z*, but the interval you report after fieldwork uses
Student's *t* on *n*−1 degrees of freedom, which is larger. So the workbook iterates —
`n ← ⌈(t(n−1)·CV/E)²⌉` — until the answer stops moving, and shows both the plain and the adjusted
figure so the adjustment is never invisible. Where the iteration settles into a two-cycle rather
than a fixed point, it takes the larger of the pair.

Every figure quoted in Part 2 comes off the `4. Sensitivity` tab, which is regenerated by
`_source/build_grass_alloc.py`. **Do not edit the numbers in the prose by hand** — re-run the
script and copy them across, so the workshop and the calculator cannot disagree.
